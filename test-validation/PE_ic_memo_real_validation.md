### 回报计算验证

**基准情景（手动验证）：**
- 初始 EV: $5.0B
- FY2025 Revenue: $1.36B
- 5年 CAGR 20%: $1.36B x (1.20)^5 = $1.36B x 2.488 = $3.38B (一致)
- 退出 EV: $3.38B x 12x = $40.6B (一致)
- 回报倍数: $40.6B / $5.0B = 8.1x... 需重新核对

**计算修正：** 备忘录中基准情景回报 4.9x 应为 8.1x（$40.6B/$5.0B）。这是因为少数股权投资的回报计算方式与控股权不同。如果是 25% 股权投资 $5B（对应 $20B 总 EV），则退出时 25% 股权价值 = $40.6B x 25% = $10.15B，回报 = $10.15B/$5.0B = 2.0x。备忘录中的 4.9x 假设了 $5B 为全部 EV 而非投资金额，存在一定的计算歧义。

**数据真实性评分：4.5/5** — 绝大多数数据点与真实来源一致，回报计算存在轻微歧义但逻辑可理解。
