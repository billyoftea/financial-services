### 一、投资亮点概述

CyberArk（NASDAQ: CYBR）是全球身份安全 (Identity Security) 领域的绝对领导者，为全球超过8,000家企业客户提供特权访问管理 (PAM) 和全面身份安全解决方案。

**核心业务数据**:

| 指标 | 数据 | 来源 |
|------|------|------|
| **总 ARR (年经常性收入)** | $14.40亿 (截至FY2025末) | CyberArk FY2025财报 |
| **ARR 同比增长** | 23% YoY | CyberArk FY2025财报 |
| **订阅 ARR** | $10.88亿+ | CyberArk Q2 2025财报 |
| **FY2025 年度收入** | $13.61亿 (同比增长36% YoY) | CyberArk FY2025财报 |
| **TAM (总可寻址市场)** | ~$600亿 (含Venafi并购扩展) | CyberArk 投资者展示 |
| **全球客户数** | 8,000+ | CyberArk 公开资料 |
| **净新增 ARR (Q4 FY2025)** | $9,900万 (创历史新高, 同比增长20%) | CyberArk FY2025财报 |

**战略差异化优势**:

1. **身份安全平台领导者**: 唯一同时覆盖人类身份和机器身份安全的统一平台，涵盖特权访问管理 (PAM)、身份威胁检测与响应 (ITDR)、机器身份管理及零信任架构
2. **Venafi 并购协同**: 2024年10月完成对Venafi的$15.4亿收购，将TAM从$500亿扩展至$600亿，整合机器证书生命周期管理能力
3. **SaaS转型成功**: 订阅收入占比持续提升，Q2 2025订阅ARR达$10.88亿，展示强劲的经常性收入质量
4. **AI驱动的安全创新**: AI-powered智能特权控制，应对AI时代身份安全威胁
5. **监管顺风**: 全球零信任法规 (如美国行政令14028、欧盟NIS2指令) 持续推动身份安全支出增长

### 三、IOI 提交要求

请在初始意向函中包含以下全部信息：

#### 3.1 估值范围

- **建议的企业价值范围** (Enterprise Value Range)：请提供非约束性的企业价值估值区间，明确是否包含：
  - 净债务的假设
  - 已发行期权/RSU的处理方式
  - 或有对价 (Earn-out) 安排（如有）

#### 3.2 对价形式

- 现金 vs. 股票比例（如适用）
- 是否包含或有对价 (Earn-out) 或股权翻转 (Rollover Equity)
- 如涉及股票对价，请说明交换比率机制及定价基准日

#### 3.3 融资来源与确定性

- 融资来源说明（自有资金、银行贷款、股权融资等）
- 融资确定性的证明（如已获得承诺函，请附上）
- 预计完成融资的时间线

#### 3.4 尽职调查要求

- 列明拟进行的主要尽调领域（财务、法律、技术、商业、人力等）
- 预计尽调周期
- 是否需要第三方顾问参与

#### 3.5 交割时间线

- 从签署到交割的预计天数
- 是否需要监管审批（反垄断、CFIUS等）及其预计时间

#### 3.6 条件与先决条件

- 任何重大条件或先决条件 (Conditions Precedent)
- 是否需要特定监管批准
- 关键假设说明

#### 3.7 买方简介与战略逻辑

- 买方公司简介（若非上市公司，请提供最近期财务数据）
- 收购CyberArk的战略逻辑与协同效应分析
