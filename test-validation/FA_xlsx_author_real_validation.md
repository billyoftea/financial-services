## 六、发现的问题与建议

### 6.1 已发现问题

1. **营业利润未集中到Inputs标签页（轻微）**
   - 问题：营业利润（114,725/123,487/133,157）在利润表标签页以蓝色硬编码方式存放，违反了"所有输入集中在Inputs标签页"的规范。
   - 建议：在Inputs标签页中增加营业利润输入行，利润表改为绿色跨表引用。

2. **缺少命名范围（Named Ranges）**
   - 问题：SKILL.md 规范要求"Named ranges for any value referenced from a deck or memo"，但当前模型未使用 Excel 命名范围。
   - 建议：为关键指标（如 Revenue、Net_Income、EPS）添加 openpyxl 的 defined_names。

3. **中文字符在终端显示乱码（非功能性）**
   - 问题：openpyxl 验证输出中中文标签页名在 bash 终端显示为乱码，但 Excel 文件内部编码正确。
   - 影响：无实际影响，仅在终端验证时显示异常。

### 6.2 改进建议

1. **Inputs标签页完善：** 将所有硬编码输入（包括营业利润）统一迁移到 Inputs 标签页，确保 100% 集中。
2. **增加更多财务比率：** 可考虑增加 D/E ratio、利息保障倍数、P/E、P/B 等估值指标。
3. **增加条件格式：** 在 Checks 标签页为 TRUE/FALSE 添加条件格式（绿色=通过，红色=失败）。
4. **添加数据验证：** 对 Inputs 标签页的数值添加 Excel 数据验证规则（如 >0），防止输入错误。

### 6.3 总结

xlsx-author 技能成功生成了格式规范、数据准确的 AAPL 三表联动模型 Excel 文件。核心规范（颜色编码、公式驱动、Inputs集中、Checks校验）执行度高。发现的两个小问题（营业利润未集中到Inputs、缺少命名范围）均为轻微规范偏差，不影响模型的实际可用性和数据准确性。
