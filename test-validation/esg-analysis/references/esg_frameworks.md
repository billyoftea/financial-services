## MSCI ESG Ratings

### 评分体系
- **评级范围**: AAA（最高）到 CCC（最低），共 7 档
- **核心方法**: 基于行业实质性议题的风险暴露与管理能力评估
- **更新频率**: 至少每年更新一次

### 关键维度
| 维度 | 权重范围 | 核心议题示例 |
|------|---------|------------|
| 环境 (E) | 行业相关 | 碳排放、水资源、生物多样性、废弃物 |
| 社会 (S) | 行业相关 | 劳动力管理、数据隐私、产品安全 |
| 治理 (G) | 行业相关 | 董事会独立性、高管薪酬、会计稳健性 |

### 行业实质性议题
MSCI 为每个 GICS 子行业定义 20-35 个关键议题，仅选取对财务影响最显著的议题加权计算。不同行业的 E/S/G 权重差异极大：
- 能源行业：E 权重可达 60%+
- 金融行业：G 权重通常最高
- 科技行业：S 和 G 权重较高

## Sustainalytics ESG Risk Rating

### 评分体系
- **评分范围**: 0（无风险）到 100+（极高风险）
- **核心方法**: 量化公司面临的未管理 ESG 风险敞口
- **风险等级划分**:
  - 0-10: 可忽略风险 (Negligible)
  - 10-20: 低风险 (Low)
  - 20-30: 中等风险 (Medium)
  - 30-40: 高风险 (High)
  - 40+: 严重风险 (Severe)

### 关键指标
- **未管理风险 (Unmanaged Risk)**: 总风险减去已管理部分
- **管理缺口 (Management Gap)**: 公司管理能力与行业最佳实践的差距
- **争议事件 (Incidents)**: ESG 相关负面事件记录

## S&P Global CSA / DJSI

### 评分体系
- **评分范围**: 0-100 分
- **核心方法**: 企业可持续发展评估（CSA），年度问卷评估
- **DJSI 入选**: 行业前 10% 可入选道琼斯可持续发展指数

### 评估维度
| 维度 | 经济 / 环境 / 社会 |
|------|-------------------|
| 经济 | 行业特定标准、公司治理、风险管理 |
| 环境 | 环境披露、环境管理、运营生态效率 |
| 社会 | 劳动实践、人权、社会贡献 |

## 评级对比表

| 特征 | MSCI | Sustainalytics | S&P Global |
|------|------|---------------|------------|
| 评分方向 | 高分=好 | 低分=好 | 高分=好 |
| 核心视角 | 行业相对表现 | 绝对风险度量 | 绝对得分 |
| 覆盖范围 | 8,500+ 公司 | 13,000+ 公司 | 10,000+ 公司 |
| 更新频率 | 年度 + 事件驱动 | 月度 | 年度 |
| 行业调整 | 是（ISS） | 是 | 是 |
| 争议监控 | 是 | 是 | 是 |

### 跨评级一致性注意
- 三家机构评级相关性约 0.5-0.7，并非高度一致
- MSCI 和 S&P Global 更关注行业相对表现
- Sustainalytics 侧重绝对风险量化
- 分析时需同时参考多家评级以降低单一评级偏差
