## 1. 折现现金流分析（DCF）

### 1.1 关键假设

| 参数 | 假设值 | 说明 |
|------|--------|------|
| 预测期 | 2025E - 2029E | 5年明确预测期 |
| 终端增长率 | 3.0% | 基于长期AI/软件支出增长 |
| WACC | 11.0% | 反映高beta (~2.0x) 和成长股风险 |
| 无风险利率 | 4.5% | 10年期美国国债收益率 |
| 股权风险溢价 | 5.5% | 标普500长期ERP |
| Beta | 2.0x | PLTR历史beta，反映高波动性 |

### 1.3 终端价值计算

采用永续增长模型（Gordon Growth Model）：

- 终端年FCF (2029E): $2,504M
- 终端增长率: 3.0%
- WACC: 11.0%
- 终端价值 = FCF(2029E) x (1+g) / (WACC - g) = $2,504 x 1.03 / (0.11 - 0.03) = **$32,239M**

### 2.2 估值倍数统计摘要

| 统计量 | EV/Revenue (NTM) | EV/EBITDA (NTM) | P/E (NTM) |
|--------|-------------------|-------------------|-----------|

### 2.3 Palantir相对估值

| 指标 | Palantir当前 | 可比中位数 | 溢价/折价 |
|------|-------------|-----------|-----------|
| EV/Revenue (NTM) | ~73x | 12.0x | +508% |
| EV/EBITDA (NTM) | ~160x | 42x | +281% |
| P/E (NTM) | ~97x | 65x | +49% |
| Revenue Growth | ~56% | 25% | +124% |

**分析**：Palantir的EV/Revenue倍数是可比公司中位数的6倍以上，即使考虑其更高的增长率（Rule of 40得分优异），估值溢价仍然极端。使用中位数EV/Revenue 12.0x应用于Palantir 2026E收入$5.22B，隐含EV约为$63B，权益价值约$70B，对应股价约$29。即使使用75th百分位16.2x，隐含股价也仅为$39。

### 2.4 增长调整后估值

考虑到Palantir的增长率（~56%）远高于可比公司中位数（~25%），我们进行PEG调整：

- Palantir PEG (基于EV/Revenue-Growth): 73/56 = 1.30x
- 可比公司中位数PEG: 12.0/25 = 0.48x
- Palantir PEG溢价: +171%

即使在增长调整后，Palantir的估值仍显著高于同行。

### 3.2 目标价确定

**目标价: $105.00**

目标价确定逻辑：
- 考虑到Palantir的独特性（政府合同壁垒、Ontology技术护城河、AI增长加速），纯粹的基本面DCF和可比分析可能低估其长期价值
- 但当前约$130的价格已经反映了极高的增长预期
- 我们给予30%的"战略溢价"（反映政府合同不可替代性和AI平台卡位价值），在可比分析中位数基础上调整
- 使用2026E收入$5.22B x 18x EV/Revenue（介于中位数12x和Palantir当前73x之间的折中值）= EV $94B → 权益价值约$101B → 股价$42
- 考虑到市场可能继续给予高增长AI公司超额估值，以及Palantir连续10个季度加速增长的趋势可能在短期内持续，我们设定12个月目标价为$105

### 3.3 投资评级与建议

**评级: HOLD（持有）**

| 项目 | 数据 |
|------|------|
| 目标价 | $105.00 |
| 当前股价 | ~$130.00 |
| 上涨空间 | -19.2% |
| 评级 | HOLD |

**评级理由**：
1. **基本面优异但估值过高**：Palantir的收入增长（连续10个季度加速）、利润率改善（EBITDA Margin 45%+）和自由现金流生成（FCF Margin 35%+）均表现优异，但EV/Revenue 73x的估值已经透支了多年的增长预期
2. **AI增长可见性高但已被定价**：AIP平台推动的商业收入增长是真实的，但市场已将其反映在价格中
3. **政府合同提供安全垫**：$100亿陆军合同提供了收入可见性，但不足以支撑当前估值
4. **估值压缩风险是主要下行因素**：任何增长低于预期的信号都可能导致估值倍数大幅压缩

### 3.4 关键催化剂（未来12个月）

1. **Q1 2026财报（即将发布）**：收入指引$1.532-1.536B，若大幅超出可能推动股价上涨
2. **AIP新客户公告**：大型企业客户的AIP部署成功案例可能提升市场信心
3. **政府合同续签/新增**：更多Titan级别合同的签署
4. **AI Agent功能发布**：AIP平台在AI Agent自动化方面的新功能可能成为股价催化剂
5. **竞争格局变化**：如果主要竞争对手（Snowflake/Databricks）增长放缓，Palantir的相对吸引力增强

### 3.5 下行风险因素

1. **增长减速**：收入增长率从50%+降至30%+水平
2. **AI投资回报质疑**：市场对AI落地效果的质疑波及Palantir
3. **内部人持续抛售**：大规模内部人股票出售引发市场担忧
4. **宏观环境恶化**：高利率环境对高估值成长股的估值压制
5. **政府合同风险**：国防预算削减或政治变动影响合同续签
