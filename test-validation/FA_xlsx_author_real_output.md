# AAPL 三表联动模型说明

**生成日期：** 2026年5月10日
**数据来源：** Apple Inc. FY2023-FY2025 10-K 年报（公开数据）
**单位：** 百万美元（股数为百万股，EPS为美元/股）

---

## 文件结构

Excel 文件包含 5 个标签页：

### 1. Inputs（输入数据）
- 所有硬编码输入数据集中存放
- 包括：收入、营业成本、总资产、总负债、经营现金流、资本支出、稀释股数、净利润
- 颜色编码：**蓝色字体** = 硬编码输入

### 2. 利润表
- 收入、营业成本、毛利润（公式）、毛利率
- 营业利润、营业利润率
- 净利润、净利润率
- 稀释EPS（= 净利润/稀释股数，公式计算）
- 颜色编码：**绿色字体** = 从Inputs跨表引用，**黑色字体** = 公式计算

### 3. 资产负债表
- 总资产、总负债（从Inputs引用）
- 股东权益 = 总资产 - 总负债（公式）
- 资产负债率、ROE、ROA

### 4. 现金流量表
- 经营现金流、资本支出（从Inputs引用）
- 自由现金流 = 经营现金流 + 资本支出（公式）
- FCF利润率、CapEx/Revenue

### 5. Checks（平衡校验）
| 校验项 | 说明 |
|--------|------|
| 资产 = 负债 + 权益 | 差值应为0 |
| 毛利润 = 收入 - COGS | 差值应为0 |
| FCF = 经营CF + CapEx | 差值应为0 |
| EPS一致性 | 计算EPS与公式EPS一致 |
| 盈利质量 | 经营CF/净利润 > 80% |
| 净利润一致性 | 利润表净利润 = Inputs净利润 |
