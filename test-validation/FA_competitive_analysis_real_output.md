### 增长驱动力
- **AI/生成式AI工作负载**：成为2024-2025年最大的增量需求来源，推动GPU基础设施和AI平台消费
- **企业数字化转型**：传统IT向云迁移的持续结构性趋势
- **混合云/多云策略**：企业采用多云架构推动整体市场扩容
- **边缘计算**：IoT和实时应用驱动边缘云需求

### 风险因素
- AI基础设施过度投资风险（供过于求）
- 地缘政治和监管不确定性（数据主权）
- 经济下行导致企业IT预算压缩

## Step 2 — 行业价值链经济学

### 云服务价值链结构

```
┌──────────────────────────────────────────────────────┐
│  基础设施层（IaaS）                                    │
│  • 数据中心、服务器、网络 — 典型毛利率 50-60%           │
│  • 规模效应显著，头部玩家具备成本优势                    │
├──────────────────────────────────────────────────────┤
│  平台层（PaaS）                                        │
│  • 数据库、AI/ML、分析工具 — 典型毛利率 65-75%          │
│  • 差异化核心，锁定效应最强                              │
├──────────────────────────────────────────────────────┤
│  应用层（SaaS）                                        │
│  • 企业应用、协作工具 — 典型毛利率 70-80%               │
│  • 附加值最高但竞争最分散                                │
└──────────────────────────────────────────────────────┘
```

### 价值流动分析
- **IaaS** 是基础但利润率最低，规模经济是关键护城河
- **PaaS**（尤其是AI平台）是当前竞争焦点，决定客户锁定深度
- 三巨头均采取"IaaS引流 + PaaS盈利"策略，AI服务成为新的PaaS battleground
- 行业呈现"赢家通吃"趋势：规模越大 → 成本越低 → 价格竞争力越强 → 吸引更多客户

## Step 4 — 竞争者分组

### 按商业模型分类

| 分类 | 厂商 | 特征 |
|---|---|---|
| **全栈平台型** | AWS, Azure, GCP | IaaS+PaaS+SaaS全栈覆盖，自研芯片，全球数据中心 |
| **垂直专精型** | Snowflake, Databricks, MongoDB | 聚焦特定PaaS层（数据/AI），依托超大规模厂商的IaaS |

| 态势 | 厂商 | 说明 |
|---|---|---|
| **直接竞争者** | AWS, Azure, GCP | 全栈IaaS+PaaS，相同客户群（企业、政府、初创） |

## Step 9 — 综合分析

### 护城河评估

| 护城河维度 | AWS | Azure | GCP |
|---|---|---|---|
| **网络效应** | 强 | 强 | 中等 |
| *评估* | 最大用户基础驱动生态飞轮，Marketplace网络效应 | M365用户基础形成天然转化通道，Copilot放大效应 | Kubernetes生态强但用户基数不足 |
| **转换成本** | 强 | 极强 | 中等 |
| *评估* | 深度架构集成提高迁移成本 | 企业Active Directory/M365绑定，转换成本行业最高 | 技术标准化（K8s）降低锁定但增加互换性 |
| **规模经济** | 极强 | 强 | 中等 |
| *评估* | 最大规模带来最低单位成本，利润率最高 | 全球第二大规模，软件层提升混合利润率 | 规模较小但增速快，单位成本改善中 |
| **无形资产** | 强 | 强 | 强 |
| *评估* | 品牌认知第一，200+服务品类 | 企业信任度最高，30年合作关系 | AI/ML技术品牌最强，数据科学心智份额高 |

### 持久竞争优势与结构性脆弱性

**AWS：**
- **持久优势：** 最大规模 → 最低成本结构；最广泛的服务组合；最早进入者的生态锁定
- **结构性脆弱：** 缺乏企业应用层绑定（vs Azure）；增速放缓反映份额被蚕食的风险
- **趋势判断：** 稳健的"现金牛"定位，但不再是"成长股"叙事

**Azure：**
- **持久优势：** Microsoft生态绑定（Office/AD/Dynamics）创造最高转换成本；OpenAI合作锁定最强AI能力
- **结构性脆弱：** 毛利率下降趋势（AI基础设施成本）；对OpenAI关系的依赖风险
- **趋势判断：** 最佳"AI变现"定位，但需管理利润率与投资的平衡

**GCP：**
- **持久优势：** AI/ML技术基因（Gemini + TPU）；数据分析栈竞争力（BigQuery）；估值最具吸引力
- **结构性脆弱：** 市场份额小（13%），企业销售能力弱，生态合作伙伴网络不足
- **趋势判断：** 增速最快的"追赶者"，从亏损到盈利的质变期，可能是最佳风险回报比
