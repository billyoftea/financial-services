## Critical Issues

### 1. Number Consistency（数字一致性）

#### 1.1 Revenue数据矛盾（Slides 2）
- **问题描述：** Slide 2中出现了两个不同的FY2026E Revenue数字。
  - 文本描述："2026年收入预计达到 **$1.5B**，同比增长35%"
  - 表格数据："FY2026E Revenue = **$1,360M**（即$1.36B）"
- **差值：** $1.5B vs $1.36B，差异约$140M（约10.3%）
- **Action：** 核实正确的Revenue预测值。若以表格$1,360M为基准，则文本中"$1.5B"应修改为"$1.36B"，同时需要重新计算35%的同比增长率是否成立。($1,360M / $1,010M - 1 = 34.7%，约35%，增长率基本一致，说明表格数字更可信，文本中的$1.5B是错误数字。)

#### 1.2 可比交易均值计算偏差（Slide 3）
- **问题描述：** Slide 3底部的均值标注为"均值 EV/Revenue: 9.1x"，但实际计算：
  - EV/Revenue数据：7.2x, 6.5x, 8.0x, 18.5x, 5.5x
  - 均值 = (7.2 + 6.5 + 8.0 + 18.5 + 5.5) / 5 = **9.14x**（与9.1x基本一致，但存在四舍五入偏差）
  - EV/EBITDA数据（仅3笔有数据）：32.5x, 35.0x, 28.0x
  - 均值 = (32.5 + 35.0 + 28.0) / 3 = **31.83x**（标注为31.8x，可接受）
- **严重程度：** 低。均值四舍五入基本正确，但Auth0的18.5x EV/Revenue显著偏离其他交易（中位数7.2x），应考虑是否使用中位数或剔除异常值，并注明理由。
- **Action：** 建议补充说明是否使用了中位数或加权平均，并标注已剔除/包含异常值。

#### 1.3 可比交易法估值交叉验证（Slides 3, 4）
- **问题描述：** Slide 4中"可比交易法 EV/Revenue 8x-10x → 隐含企业价值 $10.8B - $13.6B"
  - 需验证：如果Revenue = $1,360M（以表格为准）
  - EV = $1,360M × 8x = **$10,880M ≈ $10.9B**（与$10.8B接近）
  - EV = $1,360M × 10x = **$13,600M = $13.6B**（一致）
  - 但如果Revenue = $1.5B（以文本为准）：EV = $1.5B × 8x = $12.0B（与$10.8B不符）
- **结论：** 估值计算依赖的Revenue基数与Slide 2表格一致（$1,360M），进一步证明文本中的"$1.5B"是错误数字。
- **Action：** 修正Slide 2文本中的Revenue数字为$1.36B。

### 2. Data-Narrative Alignment（数据叙事对齐）

#### 2.1 可比交易数据过时（Slide 3）
- **问题描述：** Slide 3的可比交易数据均为2021-2023年交易，最远可追溯至Auth0/Okta在**2021年3月**的交易（距今超过5年）。
  - 2021年正值科技股估值高峰期（Auth0的EV/Revenue高达18.5x），该数据在2026年的市场环境下缺乏参考价值。
  - 未包含任何2024-2026年的近期可比交易。
- **Action：** 补充2024-2025年网络安全/身份安全领域的近期交易，或明确说明为何使用较早的交易作为参考。考虑剔除Auth0等高估值时期的交易，或标注市场周期差异。

#### 2.2 估值范围交叉验证不完整（Slide 4）
- **问题描述：** DCF分析给出"隐含股权价值 $10.2B"，但未与可比公司法（$9.5B-$11.4B EV）和可比交易法（$10.8B-$13.6B EV）进行明确对比。EV与股权价值之间的净债务调整未披露。
- **Action：** 补充净债务数据，将EV转换为股权价值后进行统一比较，并给出最终建议估值区间。

## Important Issues

### 3. Language Polish（语言规范）

#### 3.1 口语化/非投行用语（Slide 5）
以下用语不符合投资银行Pitch Deck的专业规范：

| 当前用语 | 问题描述 | 建议修改 |
|---------|---------|---------|
| "这家公司很牛！" | 口语化、使用感叹号 | "CyberArk possesses compelling competitive positioning in the identity security market." 或 "CyberArk在身份安全领域具备差异化的竞争优势。" |
| "公司的产品非常好" | 模糊、缺乏量化支持 | "产品功能覆盖领先，在Gartner Magic Quadrant中位列Leaders象限" |
| "市场份额一直在涨" | 非正式表述，缺少具体数据 | "市场份额从FY2024的X%提升至FY2026E的Y%" |
| "基本上没有竞争对手能打" | 极端措辞，缺乏依据 | "竞争格局相对集中，CyberArk在Privileged Access Management细分领域保持领先" |
| "我们觉得买家会愿意出一个很高的价钱" | 过于口语化 | "基于当前市场环境，预计买方将提供具有吸引力的收购溢价" |
| "协同效应很大！" | 模糊+感叹号 | "预计可实现的协同效应价值达$X百万，主要来源于[具体来源]" |
| "pretty much确定能卖个好价钱" | 中英混搭、口语化 | "基于上述分析，我们对交易前景持审慎乐观态度" |

#### 3.2 术语一致性问题
- Slide 2中使用"$1.5B"（B单位），表格中使用"$1,010M"/"$1,360M"（M单位）。应在整个Deck中统一使用一种单位表示法（$M或$B，不要混用）。
- "可比公司法"与"可比交易法"的使用一致，无问题。

#### 4.2 来源引用缺失（Slide 4）

- **Action：** 补充来源引用，如"来源：Bloomberg consensus, Management guidance, [投行] estimates"。
