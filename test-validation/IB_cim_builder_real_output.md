# I. 执行摘要

## 1.1 公司简介

CyberArk Software Ltd.（NASDAQ: CYBR）是全球领先的**身份安全**（Identity Security）平台公司，专注于**特权访问管理**（Privileged Access Management, PAM）和**身份威胁检测**（Identity Threat Detection and Response, ITDR）领域。公司成立于1999年，总部位于美国马萨诸塞州Newton市，同时在以色列Petah Tikva设有研发中心。

CyberArk提供业界最全面的身份安全平台，覆盖**人类身份**和**机器身份**的全生命周期管理，帮助企业保护其最关键资产免受网络攻击。公司已成功从传统许可模式转型为以SaaS订阅为核心的商业模式， FY2025订阅收入占总收入比例超过**81%**。

# II. 公司概况

## 2.1 历史沿革

CyberArk由现任首席执行官**Udi Mokady**于1999年在以色列创立。公司最初专注于**特权账户密码管理**，解决企业内部最具风险的身份安全盲点。

**发展里程碑：**

| 时间 | 里程碑事件 |
|------|-----------|
| 1999 | Udi Mokady在以色列创立CyberArk |
| 2005 | 推出Enterprise Password Vault（EPV），奠定PAM市场基础 |
| 2012 | 扩展至会话隔离和审计功能，产品线升级 |
| 2014 | **纳斯达克IPO**（NASDAQ: CYBR），募资约$1.76亿 |
| 2017-2019 | 持续产品创新，推出Cloud PAM、Conjur Secrets Manager |
| 2020 | 加速SaaS转型，推出Privilege Cloud SaaS解决方案 |
| 2021 | 收购Idaptive，扩展身份管理能力 |
| 2022 | SaaS订阅模式加速推进，ARR突破$5.7亿 |
| 2024 | **以$15.4亿收购Venafi**（机器身份管理领导者） |
| 2025 | **以$1.75亿收购Zilla Security**（IGA身份治理管理） |
| 2025 | 年收入突破$13.6亿，ARR达$14.4亿 |

## 2.2 使命与价值主张

**使命声明：** "保障全球领先组织免受网络攻击，通过全面保护人类和机器身份，消除最关键的安全漏洞。"

**核心价值主张：**

- **全面覆盖：** 唯一能够同时保护人类身份和机器身份的身份安全平台
- **深度防御：** 从特权发现、凭证保管、会话隔离到威胁检测的端到端防护
- **云原生架构：** SaaS优先的部署模式，支持混合云和多云环境
- **生态集成：** 与超过100个安全工具和IT平台深度集成

## 2.3 产品与服务

CyberArk Identity Security Platform提供业界最完整的身份安全产品组合：

### 核心产品线

**1. Privileged Access Manager (PAM)**
- 公司旗舰产品，市场占有率第一

**2. CyberArk Secrets Manager, SaaS**
- 原 Conjur Cloud，面向云原生应用的密钥管理
- 保护容器、Kubernetes、CI/CD管道中的机器凭证
- 支持多云环境（AWS、Azure、GCP）

**3. CyberArk Machine Identity Security（原Venafi）**
- 机器身份管理领域领导者
- TLS/SSL证书生命周期管理
- 代码签名和机器身份自动化
- 覆盖数十亿级别的机器身份

**4. CyberArk Identity Governance（原Zilla Security）**
- 身份治理管理（IGA）平台
- 访问请求、认证和审计自动化
- 合规报告和风险分析

**5. CyberArk Endpoint Privilege Manager (EPM)**
- 端点最小权限管理
- 应用控制和凭据盗窃防护
- 支持Windows和macOS

**6. CyberArk Identity Threat Detection & Response (ITDR)**
- 基于AI的身份威胁检测
- 实时监控异常身份行为
- 自动化响应和修复

- **客户成功：** 持续培训、最佳实践指导、健康检查

# III. 行业概况

## 3.1 市场规模与增长动力

### 总可寻址市场（TAM）

| 市场细分 | 2025年规模 | 2030年预测 | CAGR |
|----------|-----------|-----------|------|
| 身份与访问管理（IAM） | ~$260亿 | ~$426亿 | 10.4% |
| 特权访问管理（PAM） | ~$35亿 | ~$65亿 | 13.2% |
| 机器身份管理 | ~$30亿 | ~$60亿 | 14.9% |
| 身份治理管理（IGA） | ~$80亿 | ~$140亿 | 11.8% |
| 身份威胁检测与响应 | ~$20亿 | ~$50亿 | 20.1% |
| **身份安全总TAM** | **~$470亿** | **~$800亿+** | **~11.5%** |

> 来源：MarketsandMarkets, Gartner, IDC, Precedence Research (2025)

### 核心增长驱动因素

**1. 网络攻击频率和损失持续攀升**
- 2024年全球网络犯罪损失估计超过**$9.5万亿**
- 勒索软件攻击中，**80%以上**涉及凭证盗窃或特权滥用
- 身份相关安全事件是数据泄露的首要原因

**2. 零信任架构的全球性部署**
- 各国政府和监管机构推动零信任安全框架
- 身份验证是零信任的**核心第一层**
- 美国联邦政府行政命令（EO 14028）要求所有联邦机构实施零信任

**3. 云迁移和数字化转型加速**
- 全球企业持续将工作负载迁移至云环境
- 多云和混合云架构带来更多身份管理复杂性
- 机器身份数量已超过人类身份的**45:1**比例

**4. AI/GenAI带来的新身份挑战**
- AI代理（AI Agents）需要独立的身份管理和访问控制
- GenAI工具增加了敏感数据泄露的风险
- AI驱动的攻击使传统安全措施效果降低

**5. 严格的监管合规要求**
- **NIS2**（欧盟网络和信息安全指令2.0）：2024年生效
- **DORA**（数字运营韧性法案）：欧盟金融行业
- **SEC网络安全披露规则**：美国上市公司
- **中国《数据安全法》《个人信息保护法》**

## 3.2 行业趋势

**趋势一：从PAM到身份安全平台的演进**
市场正从单点PAM解决方案向综合身份安全平台转变。买方倾向于选择能够覆盖人类身份和机器身份全生命周期的统一平台。CyberArk通过有机增长和收购（Venafi + Zilla Security）已确立该方向的领导地位。

**趋势二：身份威胁检测与响应（ITDR）的崛起**
Gartner将ITDR列为2024-2025年顶级安全技术趋势。传统IAM和PAM专注于访问控制，ITDR则增加实时威胁检测能力，形成"防御+检测"的完整安全闭环。

**趋势三：机器身份爆炸式增长**
随着容器化、微服务、IoT和AI代理的普及，机器身份（服务账户、API密钥、TLS证书）的数量呈指数级增长。Venafi收购使CyberArk在这一快速增长领域占据先发优势。

**趋势四：身份编织架构（Identity Fabric）**
行业向"身份编织"架构演进，即统一的身份策略层跨越混合环境。单一供应商提供完整身份安全栈的价值主张正在被市场接受。

- 财富500强中超过50%的企业选择CyberArk

## 3.4 进入壁垒

**1. 技术壁垒**
- PAM技术复杂度高，需多年研发积累
- 企业级安全要求包括加密、审计、高可用等核心能力
- AI驱动的威胁检测需要大量训练数据和算法积累

**2. 客户切换成本**
- PAM解决方案部署后切换成本极高（集成深度大、流程依赖强）
- 安全策略和合规审计依赖特定供应商
- 客户切换涉及全组织范围的身份基础设施变更

**3. 合规与认证壁垒**
- SOC 2 Type II、ISO 27001、FedRAMP等认证获取周期长
- 特定行业（金融、政府、医疗）有额外的安全认证要求
- 监管审计中已验证的供应商更具优势

**4. 信任与品牌壁垒**
- 大型企业安全决策中，品牌声誉和行业口碑至关重要
- CyberArk 20+年的安全运营记录构成极强的信任壁垒
