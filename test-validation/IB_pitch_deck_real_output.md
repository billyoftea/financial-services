# 第1页：行业概览 — 市场定义

## 网络安全行业市场定义

**定义：**
全球网络安全行业涵盖为保护企业IT基础设施、云环境、端点设备、网络通信及数据资产免受网络威胁而提供的软件、硬件及服务解决方案。

### 市场范围 — 包含 ✓

| 领域 | 说明 | 代表企业 |
|------|------|----------|
| ✓ 云安全（Cloud Security） | 云工作负载保护、CSPM、CWPP | Wiz, Palo Alto Networks, CrowdStrike |
| ✓ 端点安全（Endpoint Security） | EDR/XDR、终端防护 | CrowdStrike, SentinelOne, Fortinet |
| ✓ 网络安全（Network Security） | 防火墙、IDS/IPS、SD-WAN | Fortinet, Palo Alto Networks, Cisco |
| ✓ 身份与访问管理（IAM） | 零信任、MFA、PAM | CyberArk, Okta, Ping Identity |
| ✓ 安全运营（SecOps） | SIEM/SOAR、威胁检测 | Splunk, Palo Alto Networks, IBM |
| ✓ 数据安全（Data Security） | DLP、加密、数据治理 | Varonis, BigID, Rubrik |

### 市场范围 — 不包含 ×

| 领域 | 说明 |
|------|------|
| × 消费级安全软件 | 面向个人用户的杀毒软件 |
| × IT基础设施硬件（非安全） | 通用服务器、交换机等 |
| × 纯IT服务/外包 | 非安全相关的IT托管服务 |

### 范围界定依据

• 聚焦企业级网络安全解决方案，与CyberShield核心业务对齐
• 包含零信任和云安全等高增长细分市场，反映行业转型趋势
• 排除消费级和通用IT产品，确保可比性

**资料来源：** MarketsandMarkets (2025), Mordor Intelligence (2025), Gartner (2025)
**注释：** (1) 市场定义基于Gartner、IDC等主要研究机构的方法论；(2) 细分市场划分参照MarketsandMarkets网络安全报告框架

## 附录A：估值方法论说明

### 可比公司分析（Public Comps）
通过比较CyberShield与上市网络安全公司的估值倍数（EV/Revenue, EV/EBITDA），推导隐含估值。考虑因素包括：规模折价、流动性折价、增长溢价。

### 可比交易分析（M&A Comps）
参考近期完成的网络安全行业M&A交易的收购倍数。考虑因素包括：交易规模差异、战略vs. PE买家、市场周期。

### DCF分析（现金流折现）
