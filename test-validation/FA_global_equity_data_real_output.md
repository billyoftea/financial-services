### 8.2 免责声明

本报告数据来源于公开市场信息，通过 WebSearch 从 Yahoo Finance 等渠道获取。由于 yfinance API 在数据采集时遇到429限频错误（Rate Limit），部分数据无法通过API直接获取，已通过网页搜索方式补充。所有数据仅供分析参考，不构成投资建议。数据截至2026年5月10日，实际价格可能与报告时点存在差异。

### 8.3 数据获取说明

原始计划使用 yfinance Python库（通过 `equity_history`, `equity_info`, `equity_financials`, `equity_actions`, `equity_recommendations` 等工具函数）获取数据。实际执行中，yfinance 因 Yahoo Finance API 的请求频率限制（HTTP 429错误）无法正常工作，因此降级为通过 WebSearch 从 Yahoo Finance、Macrotrends、CompaniesMarketCap、TipRanks 等公开网站获取等效数据。所有数据均为真实可查证的市场数据。
